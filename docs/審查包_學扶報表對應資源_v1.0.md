# 審查包：英語學扶「測驗報告 → 教學資源建議單」對照表與規格

請你以資深審查者的角度挑這份規劃的毛病。這是一份**尚未實作**的規劃，程式還沒開始寫，現在改成本最低。

---

## 一、審查指引（請照這個格式回覆）

1. **只挑問題與風險，不要稱讚，不要重寫整份計畫。**
2. 每條意見標明：
   - **優先級**：高／中／低
   - **位置**：哪一份文件的第幾節、哪一列
3. 分成四類輸出，每類用編號列表：
   - A. 遺漏的風險（包含資料正確性、個資、維護性）
   - B. 步驟順序或架構問題
   - C. 更好的替代做法
   - D. 看不懂、需要澄清的地方
4. 特別希望你檢查：
   - 「用評量重點文字比對」這個串接方式的**脆弱點**：評量系統改用字、同一句評量重點對到多題但難度差很大，這些情況規格處理得夠不夠？
   - 字詞主題分組（自訂）有沒有分錯或漏字？各年級字數應為 34／54／55。
   - 對照表裡標 ⚠️、❌ 的判斷合不合理？有沒有哪一條其實應該是 ✅ 或反過來？
   - 驗收標準夠不夠具體、能不能真的驗出錯？
   - 分級門檻（50%／75%）對「全班 14 人、每個細項只有 1～6 題」這種樣本數，是不是合理？

## 二、背景與限制（請在這些前提下審查）

**使用情境**：台灣國小英語學習扶助（補救教學）。學習扶助評量系統每學期產出「特定學生測驗報告」，老師要據此決定下一段補救教學的內容與教材。使用者是新北市國小教師，也是這個資源庫的編輯者之一。

**三份資料**：
1. 教育部《110 年國民小學英語科基本學習內容》PDF（指標的權威來源，不可改）
2. Google 試算表 `English` 工作表（237 筆有連結的資源，由三位教師維護，線上隨時會變）
3. 學扶評量系統匯出的測驗報告 xlsx（每題含評量重點與每位學生的 Ｏ／Ｘ）

**已定案、不接受重議的決策**：
- 資源試算表是唯一資料來源，由教師團隊在 Sheets 上直接維護；工具**只能讀、絕不能寫**。本機的 xlsx 備份是舊版，不可回寫。
- 用「評量重點」串接，不用學習表現代碼（1-II-x）——因為 PDF 與試算表都沒有這些代碼，而且一個代碼涵蓋多個句型。
- 對應到「單元」層級而不是個別資源，這樣編輯團隊新增資源時不必改對照表。
- 現有的資源查詢網頁是 Google Apps Script + Sheets，不重寫架構。

**技術限制**：
- Google OAuth token 目前全部失效，只能用 gviz CSV 匯出唯讀讀取試算表。
- 若之後要做成網頁版，GAS 有既有慣例：不可用 template literal、不可用 hash 路由、部署一律更新既有 deployment。
- 測驗報告含學生真名，屬個資，不可進 git、不可上傳公開網址。

**本審查包不含任何學生姓名**，文件中的數字是全班 14 人的答對人數統計。

## 怎麼讀這張表

**細項編號**的格式是 `年級-項目-編號`。編號沿用 PDF 原文，例如 `4-語音-3-1` 就是四年級語音「3-1 能辨識 a, e, i, o, u 所代表的短母音」。
字詞在 PDF 裡只有單字清單，沒有細項；但學扶報表是依**主題**出題（例如「尤其是跟動物相關的單字」），所以本表把單字**自行分組成主題**，編號寫成 `4-字詞-動物`。**這個分組是本表自訂的，不是 PDF 原有的。**

**對應單元**寫的是試算表 `English` 工作表的「單元/子分類」欄（D 欄），領域則寫在各段標題。工具會以「年級＋領域＋單元」三者一起找資源，所以之後在同一單元新增的資源會自動帶出來，不必改這張表。
「迷思概念」在各領域都叫同一個名稱，因此一定要連同領域一起比對。

**指定資源**：有些資源放在共用單元（例如「繪本資源」），這種情況要用資源名稱個別指定。

**符合度**：✅ 有專屬資源｜⚠️ 只有部分或間接相關｜❌ 沒有資源

## 1. 要解決的問題

學習扶助評量系統的「特定學生測驗報告」出來之後，老師要知道兩件事：

1. **全班**哪些指標最弱，下一段教學該先補什麼、用哪些資源
2. **每位學生**錯了哪些指標，可以分組或個別補救

目前老師得自己把評量重點對到基本學習內容，再到資源網頁一層一層找。這個工具要把這段流程自動化。

## 2. 三份資料與串接方式

```
測驗報告（每題）                  指標資源對照表                    資源試算表 English 工作表
─────────────────                ─────────────────                 ─────────────────
年級（工作表名稱）      ──┐
基本學習內容類別        ──┼──►  細項編號（如 4-句構-4）  ──►  年級＋領域＋單元 → 所有資源列
評量重點（文字）        ──┘      對應單元／指定資源              （名稱、形式、網址）
學習表現代碼（1-II-x）  ──►  只用來判斷是「聽」還是「讀」
每位學生 Ｏ／Ｘ         ──►  統計通過率、列出每位學生錯了哪些題
```

**用評量重點來串，不用學習表現代碼**。原因是 PDF 和試算表裡都沒有學習表現代碼，而且同一個代碼（例如 3-II-3）底下有好幾個句型，粒度太粗。
這個決定已記在 DECISIONS.md。

## 3. 資料來源規則

### 3.1 資源試算表：只讀，不寫

- 讀取 `English` 工作表的**線上現況**（試算表 ID 見 CLAUDE.md），用 CSV 匯出網址讀取，不需要 OAuth。
- **工具絕不寫入任何試算表**，不論是 `English`、`更新紀錄`，還是之後新增的工作表。
- **本機的 `新北英語學扶資源.xlsx` 是舊版**：2026-09-20 比對結果，線上有 258 列，本機只有 215 列；線上已經改過資源形式（例如「AI互動」）、單元名稱（例如「繪本」改成「繪本資源」），也新增了影片。**本機 xlsx 不可當資料來源，也不可用任何方式寫回或覆蓋線上試算表。**
- 如果將來要把對照表放進 Google 試算表，只能**新增一個獨立工作表**，不動既有工作表的任何欄位，而且要先經使用者確認。

### 3.2 指標資源對照表

- 審閱稿是 `docs/指標資源對照表.md`。確認後轉成機器可讀的 `data/指標資源對照.csv`，並以 CSV 作為**唯一來源**；md 改成由 CSV 產生，或標示為封存。
- CSV 欄位：`細項編號, 年級, 試算表領域, 項目, 內容, 對應單元(以｜分隔), 指定資源(以｜分隔), 符合度, 備註`
- **比對規則**另存為 `data/評量重點比對規則.csv`，見第 5 節。

### 3.3 測驗報告

- 來源：學習扶助評量系統匯出的 xlsx，檔名類似 `YYYYMM特定學生測驗報告 (英語).xlsx`。
- 工具只讀取報表，不修改原檔。

## 4. 報表格式（以 202605 版為準）

| 工作表 | 用途 | 結構 |
|---|---|---|
| `測驗報告統計表` | 依類別彙總 | 第 2 列是標題：序號、基本學習內容、學習表現/學習內容、檢測狀況統計（Ｏ／△／Ｘ／合計），H 欄起每欄是一位學生，值為 Ｏ／△／Ｘ |
| `N年級`（例如 `4年級`） | 逐題明細（**主要讀這張**） | 第 2 列是標題：題號、基本學習內容、學習表現/學習內容、評量重點、檢測狀況統計（E=Ｏ、F=Ｘ、G=合計），H 欄起每欄是一位學生，值為 Ｏ／Ｘ（全形） |

- 第 1 列是報表標題，第 3 列是統計子標題，第 4 列開始才是資料。**解析時不要寫死列號**，要用「第一欄是數字」來判斷資料列（呼應 PITFALLS 裡「不要假設第幾列是標題」這條）。
- 學生欄的標題格式是 `*****12345王小明 (4年級)`（此處為虛構示例），**實際報表含學生真名**，處理方式見第 7 節。
- 一份報表可能有好幾個年級的工作表。工作表名稱符合 `\d年級` 的都要處理。
- 學習表現可能一格寫兩個代碼（`◎1-II-7 …<br>◎3-II-2 …`）。先去掉 `<br>` 和 `◎` 再解析。

## 5. 評量重點 → 細項編號的比對規則

依「年級＋類別」分流，每一類各有規則。**比對之前先正規化文字**：全形轉半形、彎引號 `’` 轉成 `'`、合併連續空白、全部轉小寫。

| 報表類別 | 規則 | 範例 |
|---|---|---|
| 語音(字母拼讀規則) | 取「練習：」之後的文字，和該年級語音細項的 PDF 原文比對（去掉標點後子字串相符） | 「能辨識a, e, i, o, u所代表的短母音」→ 4-語音-3-1 |
| 字詞 | 用 `跟(.+?)相關` 取出主題，對到 `N-字詞-<主題>`；取不到主題就對到 `N-字詞-全部` | 「尤其是跟文具相關的單字」→ 4-字詞-文具 |
| 文法句構/字詞 | 用每個句構的**關鍵片語**比對（例如 `is it/this/that`、`what's your name`、`what color`），可能同時命中多個；含「否定」就另外加上 `N-句構-否定` | 「It's an apple.及It's red.(含否定…)」→ 4-句構-2、3、否定 |
| 常用語 | 報表只寫「常用語的聽辨」時，對到該年級的「聽說」和「聽懂」兩項；如果寫出了具體用語，就依用語清單比對 | → 4-常用語-聽說、4-常用語-聽懂 |
| 字母 | 對到 `3-字母-1`；如果寫出了具體字母，可以縮小到對應的 Unit（第二階段再做） | |
| 篇章/文本 | 對到 `N-篇章-1` | |

**比對不到的題目絕不能默默略過**。建議單最後要有「⚠️ 未對應題目」一節，列出題號、原文評量重點，請維護者補一條規則。
這種情況通常發生在新年級第一次出報表，或評量系統改了用字。

**聽／讀判斷**：學習表現代碼是 `1-` 開頭就標「聽」，`3-` 開頭就標「讀」。
第一階段只在建議單上顯示「這題考的是聽／讀」，資源本身不分聽讀，因為四年級資源在試算表裡沒有標示。第二階段是否補標，見第 10 節。

## 6. 輸出內容

### 6.1 全班建議（給授課老師）

依「細項」彙總：同一細項的多題合併計算通過率，由低到高排序。

| 分級 | 條件（暫定，待確認） | 建議 |
|---|---|---|
| 🔴 全班優先 | 細項通過率 < 50% | 下一段教學優先處理 |
| 🟡 小組加強 | 50% ≤ 通過率 < 75% | 分組補救 |
| 🟢 已掌握 | ≥ 75% | 只列出，不展開資源 |

每個 🔴、🟡 細項顯示以下內容：
- 細項編號、PDF 內容原文、相關題號與各題答對人數、這題考聽或讀
- **迷思概念**（試算表中「類型＝迷思概念」的提示）排在最前面
- 資源清單：名稱、形式圖示、連結，依形式分組（簡報／遊戲測驗／影片／電子書／AI互動／文件）
- 符合度 ⚠️、❌ 要顯示提醒，例如「本細項資源不足，建議參考三年級音韻覺識 Unit 3、4」

一題如果對應到多個細項，就計入每一個細項。例如第 22 題同時計入 4-句構-2、4-句構-3、4-句構-否定。

## 9. 維護流程

1. 新一期報表出來 → 執行工具 → 看「未對應題目」和「失效的單元鍵」兩節
2. 有未對應的題目 → 在 `評量重點比對規則.csv` 補一條規則，再重跑
3. 編輯團隊在試算表新增資源 → 不用做任何事，只要單元名稱沒改，就會自動帶出
4. 編輯團隊改了單元名稱 → 工具會列出失效的鍵 → 同步修改對照表 CSV
